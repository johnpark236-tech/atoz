# BizFlow AtoZ — Google Sheets 클라우드 저장소 설정 가이드

본 문서는 **BizFlow AtoZ**의 프로젝트 데이터(프로젝트 목록, 태스크 진행상태, 메모, 체크리스트, 매출/정산 등)를 **Google Sheets에 중앙 저장**하여, **다른 PC나 다른 브라우저에서도 동일하게 이어서 작업할 수 있도록 연동하는 방법**을 설명합니다.

---

## 5단계 초간단 연동 가이드

### 1단계: Google 스프레드시트 새로 만들기
1. [Google 스프레드시트](https://sheets.new)에 접속하여 새 문서를 만듭니다.
2. 문서 제목을 `BizFlow AtoZ Cloud DB` 등으로 지정합니다.

---

### 2단계: Apps Script 편집기 열기
1. 스프레드시트 상단 메뉴에서 **[확장 프로그램]** → **[Apps Script]**를 클릭합니다.
2. 편집기 화면이 열리면 기존에 적혀있는 `function myFunction() {}` 코드를 모두 지웁니다.
3. 이 저장소의 [`google-apps-script/Code.gs`](./Code.gs) 파일의 전체 내용을 복사하여 붙여넣고 저장(**Ctrl + S** 또는 상단 디스켓 아이콘)합니다.

---

### 3단계: 초기 설정 함수 실행 (선택 사항)
1. Apps Script 편집기 상단 툴바의 실행 함수 선택 드롭다운에서 **`setupSheets`**를 선택합니다.
2. **[실행]** 버튼을 누릅니다.
3. 최초 실행 시 "승인 필요" 팝업이 뜨면 **[권한 검토]** → 본인 Google 계정 선택 → **[고급]** 클릭 → **`제목 없는 프로젝트(으)로 이동(안전하지 않음)`** 클릭 → **[허용]**을 클릭합니다.
4. 스프레드시트에 `app_state` 시트와 기본 헤더(`key`, `json_value`, `updated_at`)가 자동 생성됩니다.

---

### 4단계: 웹 앱(Web App)으로 배포하기 (가장 중요)
1. Apps Script 편집기 우측 상단의 **[배포]** → **[새 배포]**를 클릭합니다.
2. 좌측 톱니바퀴 아이콘(유형 선택)에서 **[웹 앱(Web App)]**을 선택합니다.
3. 배포 설정을 다음과 같이 입력합니다:
   - **설명**: `BizFlow AtoZ API v1`
   - **다음 사용자로 실행 (Execute as)**: **나 (내 계정)** (기본값)
   - **액세스 권한이 있는 사용자 (Who has access)**: **모든 사용자 (Anyone)**  
     *(중요: '모든 사용자'로 설정해야 로그인/인증 절차 없이 GitHub Pages 프론트엔드에서 API를 호출할 수 있습니다.)*
4. **[배포]** 버튼을 클릭합니다.
5. 화면에 표시되는 **웹 앱 URL (Web App URL)**을 복사합니다.  
   *(예: `https://script.google.com/macros/s/AKfycb.../exec`)*

---

### 5단계: BizFlow AtoZ에 URL 연결하기

다음 **2가지 방법 중 편한 방법**을 사용하시면 됩니다:

#### 방법 A (화면에서 바로 입력 — 추천, 재빌드 불필요):
1. AtoZ 웹사이트(`https://johnpark236-tech.github.io/atoz/` 또는 로컬 개발 서버)에 접속합니다.
2. 상단 헤더 우측의 **`[클라우드 설정]`** 버튼을 클릭합니다.
3. 4단계에서 복사한 웹 앱 URL을 붙여넣고 **[저장]**을 누릅니다.
4. **[연결 테스트]** 또는 **[클라우드로 전체 내보내기]**를 누르면 즉시 Google Sheets와 연동됩니다!

#### 방법 B (환경변수 설정 후 빌드):
1. 프로젝트 루트에 `.env` 파일을 생성하거나 수정합니다.
   ```bash
   VITE_GOOGLE_SHEETS_API_URL="https://script.google.com/macros/s/AKfycb.../exec"
   ```
2. 빌드 및 배포(`npm run build` 후 GitHub Pages 배포)를 진행합니다.

---

## 코드 수정 후 재배포 방법

`Code.gs` 코드를 수정한 경우:
1. Apps Script 편집기 우측 상단 **[배포]** → **[배포 관리]** 클릭
2. 배포 목록에서 활성 배포 선택 후 **우측 상단 연필 아이콘(수정)** 클릭
3. **버전**: **[새 버전]** 선택
4. **[배포]** 클릭 (기존 Web App URL이 그대로 유지됩니다).

---

## 🔒 개발자 모드 보안 안내 (DEV_SINGLE_USER_MODE)

- 현재 구성은 **개발자 1인을 위한 개인 테스트 및 멀티 디바이스 동기화 모드**입니다.
- Google Sheets URL을 통해 데이터가 교환되므로, **주민등록번호, 비밀번호, 카드번호, 계좌 비밀번호, 비밀 API 키** 등 민감한 개인정보는 절대 입력하거나 저장하지 마십시오.
- 추후 다중 사용자(SaaS) 서비스로 확장 시에는 PostgreSQL/Supabase 및 사용자 인증(OAuth/JWT) 기반의 보안 계층으로 업그레이드될 예정입니다.
